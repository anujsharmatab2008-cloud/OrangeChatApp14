📌 About the Project
Creating digital content involves several steps — planning, scripting, designing visuals, preparing voiceovers, writing descriptions, and optimising content for different platforms.

Contentora brings all of these tasks together in one place.

Users enter a topic or video idea, select their preferred language, writing style, number of scenes, video format, and available AI model option. The platform then organises everything into a dedicated production workspace.

💡 Instead of switching between multiple tools for every task, creators can manage their entire content workflow through a single platform.

Whether you're a YouTuber, social media creator, student, beginner, or small business owner — Contentora helps you transform a simple topic into a structured content package.

⚙️ Getting Started
Prerequisites
Node.js

npm

A code editor such as Visual Studio Code

Installation
1. Clone the repository

bash
git clone https://github.com/anujrepox/contentora.git
2. Navigate to the project directory

bash
cd contentora
3. Navigate to the Frontend folder

bash
cd Frontend
4. Install dependencies

bash
npm install
5. Configure environment variables

Create a .env file inside the Frontend folder and add the required API credentials using the variable names expected by the application.

6. Start the server

bash
node server.js
7. Open the application

Visit:

text
http://localhost:5000/idea.html
